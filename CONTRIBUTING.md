# Contributing to ConNect

Thank you for helping improve ConNect.

## Issues and Noncommercial Work

Bug reports, feature proposals, testing, and documentation feedback are welcome.
You may also fork and modify the project for purposes permitted by the
[PolyForm Noncommercial License 1.0.0](LICENSE).

## Pull Requests

Open an issue before starting a code or documentation pull request. To keep the
right to license ConNect commercially centralized with Thunderbird37, a separate
written contributor agreement is required before a contribution can be merged.

Do not submit employer-owned, confidential, generated from incompatible sources,
or otherwise encumbered material. You must have the right to contribute every
part of your submission.

Submitting a pull request by itself does not transfer copyright or grant
commercial relicensing rights. The contributor agreement must be completed
separately before acceptance.
